Overview

SHAYVERI is a UCI-compliant C++20 chess engine with a classical search core, a handcrafted evaluation path, and an embedded NNUE evaluation path.

Protocol

Implements UCI for direct stdin/stdout use or engine loading inside common chess GUIs.

Hardware

Targets modern x86-64 CPUs with BMI/BMI2, LZCNT, and POPCNT support.

Book

Built from 2600+ rated games sourced from The Week in Chess (TWIC). The pipeline keeps 24-ply lines from standard-chess games where both players are rated at least 2600, aggregates observed move counts, and compiles the majority move for positions reaching at least five weighted plays. The compiled book stores only the selected move and does not embed evaluator-specific metadata. Book_Info_Depth controls optional search output for book hits, with 0 preserving the immediate book-only fast path.

make -C scripts/opening_book run_all

Evaluation Paths

There are two available evaluation paths: NNUE and HCE-classical, which can be chosen between with the UseNNUE UCI option.

Handcrafted Evaluation

  • Piece-square tables with tapered middlegame/endgame interpolation.
  • Pawn structure terms for passed, isolated, doubled, backward, chained, storming, and islanded pawns.
  • King safety, mobility, coordination, tactical pressure, outposts, tempo, and initiative.
  • Parameters tuned with SPSA and Texel tuning.

NNUE

  • Embedded default network: SHAYVERI2_5_0.nnue.
  • KB16x512: Chess768 features, 16 mirrored king buckets, 512 hidden units, and SCReLU.
  • Incremental two-perspective accumulators during search.
  • Pinned at +451.2 Elo STC and +417.7 Elo LTC over HCE-classical.
  • Compatible external Chess768, KB8, and KB16 networks can be loaded through EvalFile.
  • Trained from external Stockfish/RobotMoon-style corpora, not included here.

Search Stack

Core

  • Negamax with alpha-beta pruning and Principal Variation Search.
  • Iterative deepening with aspiration windows.
  • Quiescence search with legal check evasions at the depth floor.

Pruning

  • Null move pruning, IIR, late move reductions including improving and cut-node-aware reductions, LMP, futility pruning, reverse futility pruning, and delta pruning.
  • Singular extensions, SEE-backed move decisions, and conservative quiescence SEE pruning for non-promotion captures.

State

  • Killer moves, gravity-based main, continuation, capture, and correction histories.
  • Atomic bucketed TT, repetition detection, Lazy SMP with shared TT, and dynamic time management.

Build And Use

UCI Session

uci
isready
position startpos moves e2e4 e7e5
go movetime 1000

The default net, SHAYVERI2_5_0.nnue, is automatically embedded into the binary. Hence, the .nnue file must be at root-level only while building. An external network can be loaded through the EvalFile UCI option.

UCI Options

Hash

Transposition table size in MB.

Threads

Requested search threads, bounded by detected hardware capacity.

Ponder

Enable ponder output and search support.

OwnBook

Enable the embedded opening book.

Book_Info_Depth

Search only the selected book move and report normal depth-by-depth information. Set to 0 for the fast path.

UseNNUE

Enable or disable NNUE evaluation without changing the configured network path.

EvalFile

Set an explicit network path to load an external NNUE file.

Clear Hash

Clear the transposition table.

Minimum Thinking Time

Minimum move time in milliseconds.

Move Overhead

GUI or network delay reserve in milliseconds.

Verification

The debug harness covers perft, FEN validation, make/unmake roundtrips, en-passant edge cases, SEE, evaluation symmetry, transposition-table safety, UCI checks, opening-book behavior, deterministic single-thread search, and tactical mate-in-1 regression positions.

make test
SHAYVERI supports normal chess only. Chess960 is not advertised.
