Overview

SHAYVERI is a native chess engine written in C++. The README describes a full classical search and evaluation stack, with parameters tuned by SPSA and Texel tuning on self-play datasets. Current builds also support EvalFile net5_final.nnue, making net5 the stronger tested evaluation route when the NNUE file is available.

Protocol

Implements UCI for direct stdin/stdout use or engine loading inside common chess GUIs.

Hardware

Targets modern x86-64 CPUs with BMI/BMI2, LZCNT, and POPCNT support.

Book

Includes an embedded opening book built from 2600+ rated TWIC games with precomputed cached evaluations.

The public rating numbers come from controlled multi-engine round-robin gauntlets analyzed with Ordo. They are pool-relative, anchored to fixed-strength SF2850 and SF3000, and should not be read as universal CCRL ratings.

NNUE And HCE

SHAYVERI has two evaluation stories. The original engine is a hand-crafted evaluator with tuned chess terms. The current net5 testing path uses NNUE through EvalFile, with net5_final.nnue as the default network file in the UCI layer.

Handcrafted Evaluation

  • Piece-square tables with tapered middlegame/endgame interpolation.
  • Pawn structure terms for passed, isolated, doubled, backward, chained, storming, and islanded pawns.
  • King safety, mobility, coordination, tactical pressure, outposts, tempo, and initiative.
  • Parameters tuned with SPSA and Texel tuning.

NNUE net5

  • Loaded through the UCI EvalFile option, defaulting to net5_final.nnue.
  • Used by search when the network is successfully loaded.
  • Recorded as a real gain over HCE, though smaller than the hoped-for +300 Elo jump.
  • Tested against the same opponent binaries and tournament setup as the HCE gauntlet.

Search Stack

Core

  • Negamax with alpha-beta pruning and Principal Variation Search.
  • Iterative deepening with aspiration windows.
  • Quiescence search and check extensions.

Pruning

  • Null move pruning, LMR, LMP, futility pruning, reverse futility pruning, and delta pruning.
  • Singular extensions and SEE-backed move decisions.

State

  • Killer moves, gravity-based history tables, and two-ply continuation histories.
  • Zobrist transposition table, repetition detection, Lazy SMP, and dynamic time management.

UCI Options

Hash

Transposition table size in MB.

Threads

Number of search threads.

Ponder

Enable ponder output and search support.

OwnBook

Enable the embedded opening book.

EvalFile

NNUE network path. Defaults to net5_final.nnue.

Move Overhead

GUI or network delay reserve in milliseconds.

Verification

The debug harness covers perft, FEN validation, make/unmake roundtrips, en-passant edge cases, SEE, evaluation symmetry, transposition-table safety, UCI smoke tests, opening-book behavior, deterministic single-thread search, and tactical mate-in-1 regression positions.
